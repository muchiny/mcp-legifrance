# 03 — Formes JSON de l'API Légifrance (PISTE) et DTO serde minimaux

Axe : formes JSON réelles des réponses (fixtures enregistrées), payloads de requête, facettes, anomalies (mojibake, dates, identifiants, HTML, liens), proposition de DTO Rust minimaux pour `lf-adapter-piste`, mapping DTO → domaine (`lf-domain`), et estimation chiffrée de l'économie de contexte.

Date du rapport : 2026-10-15. Langue : français ; identifiants techniques tels quels.

---

## 0. Résumé exécutif

1. **16 fixtures** (`tests/fixtures/*.json` de la référence Python `matematicsolutions/fr-eli-mcp@d3b5b13`) couvrent 8 fonds de `/search` et 6 endpoints de consultation. Elles proviennent visiblement de **trois campagnes de capture** distinctes (indentation 1 ou 2 espaces, présence ou non de mojibake) et sont **élaguées/tronquées** de façon non documentée : elles décrivent fidèlement les *types* et la *nullabilité* des champs présents, pas les *volumes* réels.
2. **Mojibake** dans 6 fixtures (LODA/CODE/JURI, campagne v0.1.0) : 252 séquences, 13 motifs distincts (`Ã©`→`é` 184 fois…), 60 valeurs + 14 **clés** de facettes. Un ré-décodage « ISO-8859-1 → UTF-8 » **au niveau du corps entier** (tout-ou-rien) répare 100 % des cas, est l'identité sur les 10 fixtures saines, est idempotent et donne exactement le même résultat qu'une réparation champ par champ (mesuré). Piège : normaliser les espaces insécables **avant** la réparation casse 10 champs (`Ã\xa0` = `à`).
3. **Dates** sous 3 encodages (entier epoch-ms, `"YYYY-MM-DD"`, ISO `"…T00:00:00.000+0000"`), parfois mélangés dans une même réponse ; sentinelle `2999-01-01` (11 fois en ms, 6 en `YYYY-MM-DD`, 5 en ISO) ; une date négative (1804). L'OpenAPI documente que les champs `…Computed` valent `null` si la date est `>= 2222-01-01` : c'est la règle de sentinelle à adopter.
4. **Requête `/search`** : la référence envoie toujours `typeChamp=ALL` + `UN_DES_MOTS` + `PERTINENCE` + `pageNumber=1` (`server.py:133-156`). L'OpenAPI (copie tierce) expose 32 `typeChamp`, 5 `typeRecherche`, des critères imbriqués, des filtres `valeurs` / `singleDate` / `dates{start,end}` / `multiValeurs`, `secondSort`, et un fond `ALL`. Les **noms de facettes renvoyés (`facetElem`) sont les noms de filtres (`facette`)** et la structure `childs` correspond à `multiValeurs` (exemple OpenAPI `{"TRIBUNAL_ADMINISTATIF": ["Bordeaux","Lille"]}`).
5. **Consultations** : `texteHtml` porte la structure en paragraphes (`<br/>`, `<BR></BR>`, `<p>`) que `texte` perd ; `/consult/kaliText` renvoie déjà le **contenu HTML des articles** et des **liens typés avec identifiants** (`lstLienCitation`, `lstLienModification`, `<a href="…idArticle=LEGIARTI…">`) ; `/consult/juri` renvoie des **résumés officiels** (`sommaire[].resumePrincipal` / `abstrats`), une `citationJp` en prose et des `liens` dont les identifiants sont **vides**.
6. **DTO** : un module `dto` par endpoint, tolérant (pas de `deny_unknown_fields`), `Option<T>` + `#[serde(default)]` partout, helper `null_default` pour les listes (serde ne traite pas `null` comme « absent » pour `Vec`), dates brutes `RawDate` converties en `LegalDate` dans le mapping, aucun champ volumineux inutile (`data` base64 ACCO, facettes en `RawValue`).
7. **Économie de contexte mesurée** (prototype Python sur fixtures) : décision CONSTIT 32 324 caractères bruts → 15 140 (sortie actuelle de la référence) → **1 154** en `summary` (÷13 vs référence) ; décision CETAT 37 220 → 15 191 → **1 658** (÷9) ; `full` paginé à 4 000 caractères ≈ 4 240. Recherche : ≈ 370–620 caractères par hit **avec** extrait de 280 caractères, contre une sortie de référence sans extrait.

## 3. Payloads de requête exacts

### 3.1 `/search` — payload de la référence (parité)

Construit par `_build_search_payload` (`server.py:133-156`), fond mappé par `_FOND_MAP` (`server.py:91-100` : `LODA→LODA_DATE`, `CODE→CODE_DATE`, `JURI`, `CONSTIT`, `CETAT`, `CNIL`, `KALI`, `ACCO` inchangés) :

```json
{
  "fond": "LODA_DATE",
  "recherche": {
    "champs": [
      {
        "typeChamp": "ALL",
        "criteres": [
          { "typeRecherche": "UN_DES_MOTS", "valeur": "<query.strip()>", "operateur": "ET" }
        ],
        "operateur": "ET"
      }
    ],
    "filtres": [ { "facette": "DATE_VERSION", "singleDate": 1760486400000 } ],
    "pageNumber": 1,
    "pageSize": 10,
    "operateur": "ET",
    "sort": "PERTINENCE",
    "typePagination": "DEFAUT"
  }
}
```

- `filtres` contient `DATE_VERSION` + `singleDate` = `int(time.time()*1000)` (instant courant, **pas** minuit) **uniquement** pour `LODA_DATE` et `CODE_DATE` (`server.py:134-136`) ; sinon `"filtres": []` (liste vide présente). `DISCOVERY.md:23-24` : « `LODA_DATE` / `CODE_DATE` require a `DATE_VERSION` `singleDate` (epoch ms) filter ».
- `pageSize` ∈ 1..100 validé côté outil (`server.py:196-197`) ; OpenAPI : « Nombre d'éléments par page (max=100) » (`RechercheSpecifiqueDTO.page_size`, `model.py:4034`).
- Valeur de `singleDate` dans l'exemple ci-dessus : illustrative.

```rust
// lf-domain/src/text/encoding.rs — pur, sans dépendance
use std::borrow::Cow;

fn has_latin1_mojibake(s: &str) -> bool {
    let mut prev: Option<char> = None;
    for c in s.chars() {
        let u = c as u32;
        if (0x80..=0x9F).contains(&u) { return true; }                // contrôle C1
        if let Some(p) = prev {
            let pu = p as u32;
            if (0xC2..=0xF4).contains(&pu) && (0x80..=0xBF).contains(&u) { return true; }
        }
        prev = Some(c);
    }
    false
}

/// Répare un texte UTF-8 qui a été décodé à tort en ISO-8859-1. Tout-ou-rien.
pub fn repair_latin1_mojibake(s: &str) -> Cow<'_, str> {
    if !has_latin1_mojibake(s) { return Cow::Borrowed(s); }
    let mut bytes = Vec::with_capacity(s.len());
    for c in s.chars() {
        let u = c as u32;
        if u > 0xFF { return Cow::Borrowed(s); }
        bytes.push(u as u8);
    }
    match String::from_utf8(bytes) {
        Ok(r) if !has_latin1_mojibake(&r) => Cow::Owned(r),
        _ => Cow::Borrowed(s),
    }
}
```

- `texteHtml` CONSTIT : `<BR>`/`</BR>` (52 paires, majuscules, fermantes non standard) + `<br/>` ×4 + `<RECH_ECLI>…</RECH_ECLI>` ; CETAT : `<br/>` ×85 + indentation (`\n`, espaces, `\t`) + `<RECH_ECLI>` ; CNIL : `<p>`/`</p>` ; KALI `content` : `<p align="left">`, `<a href=… title=…>`, balise non refermée dans la fixture tronquée.

- `texte` (plat) : pas de balises, pas de sauts de ligne ; CONSTIT : NBSP U+00A0 ×65 et apostrophe U+2019 ×117 ; extraits ACCO : `\t` ×13 et `\n` ×9.

## 12. Proposition de DTO Rust (crate `lf-adapter-piste`, module `dto`)

### 12.1 Principes

1. **Un module par endpoint** (`dto::search`, `dto::text` pour `lawDecree`/`kaliText`, `dto::article`, `dto::juri` pour `juri`/`cnil`, `dto::acco`) ; pas de struct partagée entre endpoints pour des champs homonymes de types différents (`signataires`).
2. **Tolérance** : pas de `#[serde(deny_unknown_fields)]` (serde ignore par défaut les champs inconnus en JSON, `serde-rs.github.io/_src/container-attrs.md:40-44`) ; on ne déclare **que** les champs utilisés.
3. **Tout est optionnel** : `Option<T>` + `#[serde(default)]`. Rappels serde vérifiés dans le code : un champ `Option<T>` **absent** devient `None` (`serde/src/private/de.rs:22-24`) ; mais un champ avec `deserialize_with` **sans** `default` absent est une erreur `missing field` (`serde_derive/src/de.rs:766-806`) → **tout champ à désérialiseur personnalisé porte `#[serde(default)]`** ; `#[serde(default)]` ne couvre que l'absence (« If the value is not present », `_src/field-attrs.md:22-24`), et `Vec<T>` refuse `null` (le visiteur n'implémente que `visit_seq`, `serde_core/src/de/impls.rs:1135-1175`) → helper `null_default` pour toutes les listes (des listes `null` existent : `textTitles[].appellations`).
4. **Dates brutes** : `RawDate` dans le DTO (fidèle à l'API), conversion en `LegalDate` du domaine dans le mapping (règle de sentinelle ≥ 2222-01-01).
5. **Chaînes vides** : `""` → `None` via `opt_nonempty` pour les champs où `""` signifie « absent » (`liens[].id`, `nota`, `numLoiDef`, `citationJp` CETAT, `textTitles[].nor`…), sans retoucher le contenu des chaînes non vides (pas de `trim` du texte juridique ; `trim` seulement sur titres/identifiants dans le mapping).
6. **Réparation d'encodage avant `serde`** (§11.1) ; limite de taille du corps (ex. 8 Mo, à décider) ; ne jamais déclarer `acco.data`.
7. Le domaine ne dépend pas de serde : les DTO restent dans l'adapter ; les vues de sortie MCP sont dans `lf-adapter-mcp`.
8. Désérialisation : `serde_json::from_slice` (serde 1.0.229, serde_json 1.0.154 = dernières versions non retirées vues dans l'index sparse le 2026-10-15 ; leur âge ≥ 2 semaines exigé par le brief est **NON VÉRIFIÉ**, l'index ne donne pas de date) ; erreurs enrichies par `serde_path_to_error` 0.1.20 (optionnel) pour un `CorpusError::Decode { path }` exploitable.

```rust
use serde::{de, Deserialize, Deserializer};
use std::fmt;

/// `null` ou absent -> Default (listes, maps).
pub fn null_default<'de, D, T>(d: D) -> Result<T, D::Error>
where D: Deserializer<'de>, T: Default + Deserialize<'de> {
    Ok(Option::<T>::deserialize(d)?.unwrap_or_default())
}

/// `null` / absent / "" / blanc -> None ; sinon la chaîne telle quelle.
pub fn opt_nonempty<'de, D>(d: D) -> Result<Option<String>, D::Error>
where D: Deserializer<'de> {
    Ok(Option::<String>::deserialize(d)?.filter(|s| !s.trim().is_empty()))
}

/// Date brute telle que l'API l'envoie : entier ms, chaîne de chiffres, "YYYY-MM-DD",
/// "YYYY-MM-DDTHH:MM:SS.sss+0000". Bool / objet / flottant non entier -> None (toléré, tracé).
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum RawDate { Millis(i64), Text(String) }

pub fn opt_raw_date<'de, D>(d: D) -> Result<Option<RawDate>, D::Error>
where D: Deserializer<'de> {
    struct V;
    impl<'de> de::Visitor<'de> for V {
        type Value = Option<RawDate>;
        fn expecting(&self, f: &mut fmt::Formatter) -> fmt::Result { f.write_str("date Légifrance") }
        fn visit_unit<E: de::Error>(self) -> Result<Self::Value, E> { Ok(None) }
        fn visit_none<E: de::Error>(self) -> Result<Self::Value, E> { Ok(None) }
        fn visit_some<D2: Deserializer<'de>>(self, d: D2) -> Result<Self::Value, D2::Error> { d.deserialize_any(self) }
        fn visit_i64<E: de::Error>(self, v: i64) -> Result<Self::Value, E> { Ok(Some(RawDate::Millis(v))) }
        fn visit_u64<E: de::Error>(self, v: u64) -> Result<Self::Value, E> { Ok(i64::try_from(v).ok().map(RawDate::Millis)) }
        fn visit_f64<E: de::Error>(self, v: f64) -> Result<Self::Value, E> {
            Ok((v.fract() == 0.0 && v.abs() < 9.0e15).then(|| RawDate::Millis(v as i64)))
        }
        fn visit_bool<E: de::Error>(self, _: bool) -> Result<Self::Value, E> { Ok(None) } // jamais une date
        fn visit_str<E: de::Error>(self, v: &str) -> Result<Self::Value, E> {
            let t = v.trim();
            if t.is_empty() { return Ok(None); }
            if let Ok(ms) = t.parse::<i64>() { return Ok(Some(RawDate::Millis(ms))); } // "1546819200000"
            Ok(Some(RawDate::Text(t.to_owned())))
        }
    }
    d.deserialize_option(V)
}

/// Chaîne ou nombre -> Option<String> (idcc, sizeAttachment...).
pub fn opt_string_or_number<'de, D>(d: D) -> Result<Option<String>, D::Error>
where D: Deserializer<'de> {
    #[derive(Deserialize)] #[serde(untagged)] enum SN { S(String), N(i64) }
    Ok(match Option::<SN>::deserialize(d)? {
        Some(SN::S(s)) if !s.trim().is_empty() => Some(s),
        Some(SN::N(n)) => Some(n.to_string()),
        _ => None,
    })
}
```

### 12.8 Mapping DTO → domaine

Fonctions pures dans `lf-adapter-piste::mapping` (prenant un DTO, rendant une entité `lf-domain` ou `CorpusError::Decode`/`NotFound`). Règles communes : (a) `id` absent → `NotFound` (parité `citations.py:206`, `:251`, `:330`, `:371`, `:409`, `:452`) ; (b) identifiants parsés en newtypes (`FromStr`), suffixe `_JJ-MM-AAAA` → `VersionDate` ; (c) dates : `RawDate` → `LegalDate` (ms via `from_timestamp_millis` en UTC → date civile ; `YYYY-MM-DD` ; ISO `+0000` → partie date ; année ≥ 2222 → `Open`/`None`) ; (d) texte : `texteHtml` → `Vec<Paragraph>` sinon `texte` → 1 paragraphe ; (e) `<mark>` retirés ; titres/identifiants `trim` ; (f) statut juridique : `etat` puis `jurisState` → `LegalStatus` insensible à la casse avec `Other(String)`.

**`SearchHit`** ← `SearchResultDto`
| Domaine | Source | Règle |
|---|---|---|
| `id: DocId` | `titles[0].id` | préfixe → variante typée ; suffixe → `version_date` |
| `version_date: Option<VersionDate>` | suffixe de `titles[0].id` | `JJ-MM-AAAA` |
| `cid: Option<DocId>` | `titles[0].cid` | `JORFTEXT` pour LODA |
| `title` | `titles[0].title` | sans `<mark>`, `trim` |
| `fond` / `kind` | fond demandé (parité) ; contrôle `origin` | — |
| `nature: Nature` | `nature` | normalisée (`arret`→`Arret`, `qpc`→`Qpc`…), brut conservé |
| `status` | `etat` (textes) / `solution` (décisions) | — |
| `date` | `date` → `datePublication` → `dateSignature` | `LegalDate` |
| `snippet` | `text` sinon `extracts[0].values[0]` | sans `<mark>`/`<br/>`, ≤ 280 caractères |
| `matched_in` | `extracts[].searchFieldName` | dédupliqués (ex. `Résumé principal`) |
| `official_summary` | `resumePrincipal[]` (JURI/CETAT) | nettoyé, ≤ 400 caractères |
| `articles` (CODE) | `sections[].extracts[]` avec `id` `LEGIARTI` | `{article_id, num, snippet}` (parité `citations.py:150-165`) |
| `idcc`, `company`, `themes` | `idcc`, `raisonSociale`, `themes` | ACCO |
| `aliases` | `appellations` | LODA |
| `citation` | `title` ; ACCO `"{title} ({raisonSociale})"` | parité `citations.py:141-142` |
| `source_url` / `eli_uri` | URL Légifrance par kind | parité `citations.py:76-102` |

**`SearchPage`** ← `SearchResponseDto` : `total = total_result_number.unwrap_or(hits.len())` ; `page`, `page_size` de la requête ; `next_type_pagination = type_pagination` (à renvoyer) ; `has_more = page * page_size < total` ; facettes optionnelles (`Vec<Facet{name, field, values: Vec<(String,u64)> top-N, children}>`).

## 13. Estimation de l'économie de contexte

Méthode : `dto_sizes.py` reconstruit, à partir des fixtures **réparées**, (a) une sortie `summary` = métadonnées + citation + URL + résumé officiel (`resumePrincipal` non vides, ≤ 3 × 400 caractères ; sinon `abstrats` ; sinon dispositif extrait pour CONSTIT) + `text_stats {chars, paragraphs}` ; (b) `full` page 1 = métadonnées + paragraphes jusqu'à 4 000 caractères + `next_offset` ; (c) `full` complet = métadonnées + tous les paragraphes. Les tailles de la référence sont celles de `01-parite-golden.json` (`tool_output`). Unité : caractères de JSON compact. Les noms de champs du prototype sont indicatifs.
