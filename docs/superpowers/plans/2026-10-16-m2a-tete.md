## Global Constraints

- Rust edition 2024, `rust-version = "1.88"` (job `msrv` inchangé : `cargo +1.88 check --workspace --all-targets --locked`). Toolchain `channel = "1.99.0"`, `profile = "minimal"`, composants `clippy`, `rustfmt`, `llvm-tools-preview` (tâche 1) ; chaque montée de toolchain = une PR dédiée qui aligne aussi les étapes `dtolnay/rust-toolchain` de la CI.
- Crates préfixés `lf-` ; le paquet de `crates/lf-app` s'appelle `mcp-legifrance` ; identifiants Rust en anglais et ASCII ; docs et commentaires en français ; messages d'erreur en anglais ; citations en français correct (Q16).
- `lf-domain` : dépendance normale unique `thiserror` ; dev : `proptest`, `pretty_assertions`. Aucune I/O, aucun async, aucun `unsafe` (`unsafe_code = "forbid"`).
- Lints : `clippy::pedantic` en `warn` ; `unwrap_used`, `expect_used`, `dbg_macro`, `todo`, et (tâche 1) `panic`, `unreachable`, `unimplemented` en `warn` ; tout devient bloquant par `-D warnings`. `unwrap`/`expect` permis dans les tests seulement (`clippy.toml`).
- Règles d'architecture vérifiées par `cargo xtask check-arch` (`make arch`), table `RULES` de `xtask/src/arch.rs` (tâche 4) : un membre inconnu est une violation.
- `--locked` sur toute commande cargo du `Makefile`, de la CI et de cargo-mutants (tâche 6) ; `--all-features` sur lint, test, doc et deny.
- Actions GitHub épinglées par SHA complet, version en commentaire (tâche 6) ; `workflow-lint` (zizmor + actionlint) dès que `.github/` change.
- Âge minimal des dépendances : toute version ajoutée ou montée dans `Cargo.lock` est publiée depuis au moins 14 jours (00 §2 ; contrôle `make min-age`, tâche 8) ; exception : libellé `security-fix`.
- Qualité (00 §10) : TDD ; `make cov` = 100 % des lignes, régions et fonctions (`--lib`) ; `make mutants FILE=<fichier touché>` = 0 `MISSED` et 0 `TIMEOUT`, un fichier à la fois, jamais plusieurs fichiers ni tout le workspace en local. Aucun `exclude_re` sans preuve d'équivalence. Toute boucle garantit sa progression, même mutée. Dans les tests : ni `assert!` avec message non capturé, ni `assert!(matches!(…))`, ni `let … else { panic!() }`. Logique hors des constructeurs `new` (cargo-mutants ne mute jamais `new`, tâche 16).
- WSL (`~/.claude/rules/wsl-safety.md`) : jamais `cargo test -j 4` ni plus ; `cargo mutants` uniquement par `make mutants` (contrôle mémoire, `TMPDIR=/var/tmp`, `NEXTEST_TEST_THREADS=2`, `-j 1`, un fichier).
- Toute règle portée de la référence Python cite `fichier:ligne` ; toute divergence assumée est écrite en commentaire avec sa raison.
- Commits : un par tâche (ou deux quand la tâche le dit), message en français au format conventionnel, trailer `Co-Authored-By` ajouté par le contrôleur.

## Review Focus

1. **Suffixe de version hostile ou impossible** (`LEGITEXT000006070721_31-02-2023`, `_foo`, `_` seul) : refusé par `BadSuffix`, jamais retiré en silence ; un suffixe bien formé hors `LEGITEXT` est toléré puis retiré. Tests : tâche 12, `checks_head_then_prefix_then_suffix`, `suffix_kept_on_legitext_stripped_elsewhere` et le proptest `impossible_suffix_date_is_bad_suffix`.
2. **Date de fin sentinelle** (2999-01-01, 2222-02-22, et toute date ≥ `SENTINEL_FLOOR` 2222-01-01) dans un champ de validité : lue comme « sans fin » (`None`), jamais affichée comme une date. Tests : tâche 13, `open_ended_maps_sentinels_to_none` et `epoch_ms_bounds_feed_open_ended_and_version_date`.
3. **Texte sain qui ressemble à du mojibake** (« Ã » légitime, caractère au-delà de U+00FF, espace insécable après un accent) : laissé intact ; la réparation est idempotente et refuse plutôt que d'abîmer. Tests : tâche 15, `does_not_touch_text_with_chars_above_ff`, `refuses_residual_pattern`, `accent_before_nbsp_is_a_known_false_refusal` et le proptest `idempotent`.
4. **Table des matières profonde ou hostile** (65 niveaux, doublons, sections sans titre) : `TocTooDeep` au-delà de `TOC_MAX_DEPTH` = 64, sans débordement de pile ; pagination sans entrée perdue ni dupliquée. Tests : tâche 11, `toc_depth_65_is_too_deep`, `toc_dedups_articles` et le proptest `pages_partition_the_toc`.
5. **Workspace qui grandit** (un `lf-adapter-dila` ajouté sans ligne de règle, une exigence interne `^0.0` au lieu de `=0.0.0`, une seconde cible `bin`) : `check-arch` échoue fermé avec un message par violation. Tests : tâche 4, `unknown_member_is_a_violation`, `internal_requirement_equals_workspace_version` et `check_arch_detects_each_rule`.

    fn broken_invariants(raw: &str) -> Vec<&'static str> {
        let visible: String =
            raw.chars().filter(|c| c.is_whitespace() || !c.is_control()).collect();
        let folded = visible.split_whitespace().collect::<Vec<_>>().join(" ");
        let checks = match CitationText::new(raw) {
            None => vec![("None only without content", folded.is_empty())],
            Some(t) => {
                let s = t.as_str();
                let again = CitationText::new(s);
                let cut = folded.chars().count() > CITATION_MAX_CHARS;
                vec![
                    ("never empty", !s.is_empty()),
                    ("at most 1000 chars", s.chars().count() <= CITATION_MAX_CHARS),
                    (
                        "no control, U+0020 only",
                        s.chars().all(|c| !c.is_control() && (c == ' ' || !c.is_whitespace())),
                    ),
                    ("trimmed, single spaces", !s.contains("  ") && s.trim() == s),
                    ("same text again", again.as_ref().map(CitationText::as_str) == Some(s)),
                    ("fixed point unless cut", t.is_truncated() || again == Some(t.clone())),
                    ("cut beyond 1000 only", t.is_truncated() == cut),
                    ("whole text unless cut", cut || s == folded),
                    (
                        "prefix and ellipsis if cut",
                        !cut || s.strip_suffix('…').is_some_and(|head| folded.starts_with(head)),
                    ),
                ]
            }
        };
        checks.into_iter().filter_map(|(name, ok)| (!ok).then_some(name)).collect()
    }

```rust
/// Nombre d'articles du brouillon, profondeur contrôlée : `budget` est le
/// nombre de niveaux encore permis à `sections` et `articles` (A5).
fn weigh(
    sections: &[SectionDraft],
    articles: &[ArticleDraft],
    budget: u16,
) -> Result<usize, DomainError> {
    if budget == 0 && !(sections.is_empty() && articles.is_empty()) {
        return Err(DomainError::TocTooDeep { max: TOC_MAX_DEPTH });
    }
    // Un niveau de moins par appel : au plus TOC_MAX_DEPTH + 1 appels imbriqués.
    sections.iter().try_fold(articles.len(), |total, section| {
        Ok(total + weigh(&section.sections, &section.articles, budget - 1)?)
    })
}
```

## Task 12 : suffixe de version vérifié (`parse_versioned`, `BadSuffix`, `SearchHit.version_start`)

**Décision (doc de module de `id.rs`, section `# Suffixe de version`, en substance) :** un suffixe est bien formé s'il compte exactement dix octets `JJ-MM-AAAA` (chiffres ASCII) formant une vraie date, années 1 à 9999. Tout autre suffixe (`_` seul, `_foo`, `_31-02-2023`, `_2023-09-08`…) est refusé par `DomainError::BadSuffix`, quels que soient le préfixe et l'analyseur ; la référence jetait tout suffixe sans contrôle (`citations.py:55-63`). `parse_versioned` lit un `LEGITEXT` et garde la date du suffixe (date de version par défaut de `fr_get_act`, `version_start` des résultats de recherche) ; les autres analyseurs (`Id::parse` et `FromStr`, `AnyId::parse`, `ArticleId::parse`, `DecisionId::parse`, `SectionId::parse`) tolèrent un suffixe bien formé puis le retirent, sur tout préfixe, `LEGITEXT` compris. Signaler un suffixe amont hors `LEGITEXT` (diagnostic, compteur) revient au mapper : le domaine ne journalise pas. Ordre des contrôles : forme de la tête, puis préfixe attendu, puis suffixe ; lu comme `LEGITEXT`, `JORFTEXT000020445850_foo` donne donc `InvalidId` (la famille d'abord, message le plus utile) et `LEGITEXT000033205014_foo` donne `BadSuffix`. Tous les analyseurs tolèrent les espaces autour et la casse.

**Décision (paragraphe ajouté à `CONTRIBUTING.md`, section « Mutants survivants », mot pour mot au commit 2) :** cargo-mutants ne mute jamais une fonction nommée `new` ni un `impl Default` (wiki de cargo-mutants, page « Mutations », section « General exclusions » : « Functions called `new`, and implementations of `Default` are skipped » ; <https://github.com/sourcefrog/cargo-mutants/wiki/Mutations>). Une décision écrite dans leur corps échappe donc à la mutation. Règle : une fonction `new` et un `impl Default` écrit à la main ne prennent aucune décision (ni `if`, ni `match`, ni opérateur booléen, de comparaison ou arithmétique, ni appel à une méthode qui décide à leur place, comme `filter`, `is_none` ou `unwrap_or_else`). Ils assemblent leurs arguments dans la struct et confient tout calcul à une fonction privée nommée autrement, mutée normalement (`CivilDate::checked`, `Coverage::checked`, `cut_snippet`…). Préférer une forme qui donne des mutants viables : un retour `Self` sans `Default` ne produit qu'un mutant non compilable, une décision écrite avec un opérateur (`!`, `&&`, `>`) en produit de vrais. Contrôle : `cargo mutants --list --file <chemin>` liste les mutants de la fonction privée.

/// Date civile tirée de trois entiers (`None` hors calendrier) et sa date de
/// version (`None` aussi hors de `MIN..=MAX`) : la lecture du texte et la
/// conversion depuis `CivilDate` s'accordent.
fn draw((year, month, day): (u16, u8, u8)) -> (Option<CivilDate>, Option<VersionDate>) {
    let civil = CivilDate::new(year, month, day);
    let version = civil.and_then(|date| VersionDate::try_from(date).ok());
    if let Some(date) = civil {
        assert_eq!(VersionDate::parse(&date.to_string()).ok(), version);
    }
    (civil, version)
}

    let (a, b, millis, text) = input;

    // Lecture stricte : toute date acceptée s'écrit comme l'entrée, se relit à
    // l'identique et reste dans MIN..=MAX.
    if let Ok(date) = VersionDate::parse(text) {
        assert_eq!(date.to_string(), text);
        assert_eq!(VersionDate::parse(&date.to_string()), Ok(date));
        assert!(VersionDate::MIN <= date && date <= VersionDate::MAX);

    // DateRange::new ne panique jamais : sans borne, `None` ; une borne absente

    let ((civil_a, from), (civil_b, to)) = (draw(a), draw(b));

            assert_eq!(

    }
